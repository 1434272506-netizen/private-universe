# 照片放在这里

此目录已保存用户于 2026-10-29 提供的 10 张原始 JPEG：photo-01-original.jpg 至 photo-10-original.jpg。文件与附件逐字节一致，未重编码、裁切或缩放。src/personal-content.js 的 providedPhotoImport 按顺序记录路径、尺寸、字节数和 SHA-256；首次打开时导入本机收藏，之后可在网页编辑说明。

- 文件放在 `public/memories/照片名.jpg`，配置填写 `/memories/照片名.jpg`。
- 推荐 JPG、PNG、WebP；日期不确定可以留空。
- 配置只能引用本目录及其子目录，不能写 `../`、外部网址或电脑绝对路径。
- 添加后在项目目录运行 `npm run check:content`，再运行 `npm run dev` 查看效果。

完整照片与信件添加步骤见项目根目录的 `CONTENT-GUIDE.md`。
