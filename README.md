# PRIVATE UNIVERSE

给两个人的私人春日花园。PC 展示优先，以 Vite + JavaScript + Three.js 实时渲染，可环绕观察、靠近物件并发现隐藏入口。2026-10-29 已恢复误回退的水深、植被、接触阴影和远景精修，并接入 Blender/MTree 实际制作的中心母树 GLB；保留照片大图和逐封信件阅读。

## 中心母树

实际模型为 `public/models/love-tree.glb`，包含连续融合的枝干与板根、宽冠叶幕、真实树皮/透明橡叶贴图和 `RibbonAnchor` 挂点。丝带、相机近景与遮挡注册在模型加载后初始化；加载失败时显示“重新打开”，不会提前进入未完成的场景。

模型约 68,000 三角面、7.55 MB。制作源代码、重建步骤和纹理在 [scripts/authoring](scripts/authoring/README.md)，来源许可在 [模型许可说明](public/models/love-tree-LICENSES.md)。`mother_tree_*.jpg` 为 AI 概念参考，当前真实效果请看浏览器或最新实机截图。

## 启动

在项目目录用 PowerShell 执行：

```powershell
npm install
npm run dev
```

打开 Vite 打印的地址，默认是 [本地花园](http://127.0.0.1:5173/)。当前服务仅绑定本机，手机不能直接通过这个地址访问。

## 观看与探索

- 场景在奶油白邀请页后准备；准备完成后，点击「进入这座花园」。本轮开场约 9 秒，可随时跳过，也可选择「直接看花园」。9 秒是此次实现的简化时长，不代表原聊天中的约 25 秒分镜已完整实现。
- 开场结束停在完整岛屿全景。拖动鼠标环绕，滚轮在限定距离内缩放；初次探索只有短暂的轻微暗示。
- 轻点树枝上的白丝带，镜头靠近并展开布质照片长卷；轻点信箱，箱门打开并显示信纸阅读层；轻点长椅空位，进入坐着看风景的低视角。
- 关闭阅读层或点击「回到花园」，返回之前的观察位置。Esc 可收起内容或退出物件视角，R 返回花园全景。
- 「缓缓环游」由观看者主动开启，拖动或返回时停止。右上角可打开说明和全屏；说明内另有键盘可用的物件入口，以及重看开场的操作。
- 已移除底部观看位置 dock，主要内容通过真实场景物件进入。系统开启「减少动态效果」时，跳过开场运镜并减少环境运动与过渡。

## 真实内容

当前尚未提供真实照片或信件，白丝带和信箱显示空状态；没有自动生成情侣回忆、示例情书或虚构日期。

配置内容后，照片可点击放大，使用前后按钮或左右方向键切换；信件从信封列表逐封打开。详情中的 Esc 返回列表，再按一次关闭阅读层。图片读取失败有文字替代，长信和长标题可滚动阅读。

维护者可在 `src/personal-content.js` 配置内容：

| 配置 | 字段 |
|---|---|
| `memories` | `image`、`caption`、`date` |
| `letters` | `title`、`body`、`from`、`date`、`identity` |

照片文件可放入 `public/memories/`，`image` 使用 `/memories/文件名.jpg` 一类路径。`identity` 使用 `purple` 或 `green`：紫色代表用户，绿色代表她。当前配置随本地源码和构建产物提供；尚无网页上传、编辑、寄信或服务器保存功能。

## 场景与结构

主岛保留左侧记忆树、枝头白丝带、中部浅溪与天然踏石、前右薄瀑，以及右侧奶油白信箱和浅橡木长椅。白色雏菊、淡紫野花、少量柔和彩球、厚实不规则岩土断面、低处云层和远处小岛共同形成高空春日空间。

当前入口为 `src/natural/engine.js`。地形、材质、植物、水、道具与天空位于同目录的独立模块；`src/stories.js` 负责读取个人内容并生成阅读层。旧原型文件保留，但不由当前入口引用。河石和植物使用实例化，家具合并网格，远岛降低细分；没有进行目标设备的正式帧率基准测试。

## 检查

开发服务在 5173 端口运行时，在另一个终端执行：

```powershell
npm run build
node scripts/review-overall-design.mjs
node scripts/review-stories.mjs
```

也可在开发服务运行时执行 `npm test`，依次运行场景、阅读和新树专用检查；`npm run test:tree` 单独验证 GLB、尺寸、挂点、遮挡、GTAO、实体点击及加载失败重试。新树检查记录在 `work/qa/love-tree/`。

该脚本使用本机 Edge 与 Playwright，检查邀请页、可跳过开场、场景物件点击、阅读层与空状态、返回镜头、拖动和点击的区分、长椅视角、缩放边界、减少动态效果及多视角渲染。结果写入 `screenshots/overall-design-review.json`，截图为 `screenshots/design-*.png`。

`review-stories.mjs` 仅在测试浏览器中临时注入带明确测试标记的图片和信件，检查有内容状态、坏图、长信、详情导航与窄屏布局；不修改个人内容配置。结果为 `screenshots/stories-review.json`，截图为 `stories-fixture-*`。

检查生产构建时，先运行：

```powershell
npm run build
npm run preview -- --port 5174 --strictPort
```

保留预览服务，在另一个终端执行：

```powershell
node scripts/smoke-production.mjs
```

生产检查默认访问 `http://127.0.0.1:5174/`，记录在 `screenshots/production-review.json`。可通过 `BROWSER_PATH` 指定 Chromium 系浏览器路径，通过 `PREVIEW_URL` 或 `PRODUCTION_PREVIEW_URL` 改变对应检查地址。`scripts/review.mjs` 已转为当前完整检查的兼容入口。2026-10-29 实施轮构建和 49 项检查通过（19 场景、9 阅读、14 新树、7 生产），详细证据与限制见 `REPORT-2026-10-29-TREE-IMPLEMENTATION.md`。
