# PRIVATE UNIVERSE

给两个人的私人春日花园。PC 展示优先，以 Vite + JavaScript + Three.js 实时渲染，可环绕观察、靠近物件并发现隐藏入口。2026-10-29 已恢复误回退的水深、植被、接触阴影和远景精修，并接入 Blender/MTree 实际制作的中心母树 GLB；保留照片大图和逐封信件阅读。

本次画面收尾进一步调整天空/低云与薄瀑、近景文字对比和阅读排版。白丝带从实际枝头投影位置延展为布质相册，关闭后收回；减少动态效果时直接呈现。用户提供的 10 张原图已导入，添加步骤见 [照片与信件添加指南](CONTENT-GUIDE.md)。

## 中心母树

实际模型为 `public/models/love-tree.glb`，包含连续融合的枝干与板根、宽冠叶幕、真实树皮/透明橡叶贴图和 `RibbonAnchor` 挂点。丝带、相机近景与遮挡注册在模型加载后初始化；加载失败时显示“重新打开”，不会提前进入未完成的场景。

模型约 68,000 三角面、7.55 MB。制作源代码、重建步骤和纹理在 [scripts/authoring](scripts/authoring/README.md)，来源许可在 [模型许可说明](public/models/love-tree-LICENSES.md)。`mother_tree_*.jpg` 为 AI 概念参考，当前真实效果请看浏览器或最新实机截图。

## 启动

在项目目录用 PowerShell 执行：

```powershell
npm install
npm run dev
```

打开 Vite 打印的地址，默认是 [本地花园](http://127.0.0.1:5173/)。当前服务仅绑定本机，手机不能直接通过这个地址访问。

## 观看与探索

- 场景在奶油白邀请页后准备；准备完成后，点击「进入这座花园」。本轮开场约 9 秒，可随时跳过，也可选择「直接看花园」。9 秒是此次实现的简化时长，不代表原聊天中的约 25 秒分镜已完整实现。
- 开场结束停在完整岛屿全景。拖动鼠标环绕，滚轮在限定距离内缩放；初次探索只有短暂的轻微暗示。
- 轻点树枝上的白丝带，镜头靠近并展开布质照片长卷；轻点信箱，箱门打开并显示信纸阅读层；轻点长椅空位，进入坐着看风景的低视角。
- 关闭阅读层或点击「回到花园」，返回之前的观察位置。Esc 可收起内容或退出物件视角，R 返回花园全景。
- 「缓缓环游」由观看者主动开启，拖动或返回时停止。右上角可打开说明和全屏；说明内另有键盘可用的物件入口，以及重看开场的操作。
- 已移除底部观看位置 dock，主要内容通过真实场景物件进入。系统开启「减少动态效果」时，跳过开场运镜并减少环境运动与过渡。

## 真实内容

2026-10-29 已按用户提供的顺序导入 10 张真实照片，原 JPEG 与附件逐字节相同，保留分辨率与比例，不裁切。首次打开自动进入本机收藏，可在页面添加说明和日期、编辑或移除；相册提供「打开原图」。信件仍为空，没有代写经历、情书或日期。

点击白丝带直接看一页一张的相册，使用上一页/下一页、左右方向键或触摸横滑翻页，Home/End 到首尾。照片在固定画框内完整等比显示，说明较长时独立滚动；翻页前先解码相邻图片，再用轻微位移和淡入切换。按钮不随照片重建，连续操作累计目标页，收起后再次打开会接着本次读到的位置。Esc 一次关闭相册；信件仍从信封列表逐封阅读，Esc 先返回信封再关闭。阅读层稳定后暂停背景 3D 渲染和场景时钟，收起后恢复。

维护者可在 `src/personal-content.js` 配置内容：

| 配置 | 字段 |
|---|---|
| `memories` | `image`、`caption`、`date` |
| `letters` | `title`、`body`、`from`、`date`、`identity` |

进入花园后，右上角「＋ 收藏一段」可以直接添加照片和信件，空相册与空信箱也有添加入口。支持预览、填写、保存、编辑、两步移除及收藏备份恢复。页面添加的内容保存在当前设备、浏览器和网址下的 IndexedDB，照片以 Blob 保存；成功后即时更新阅读层，刷新仍保留。清理网站数据前需下载备份；没有服务器同步或自动寄信能力。完整使用说明见 [内容指南](CONTENT-GUIDE.md)。

维护者预置照片仍可放入 `public/memories/`，`image` 使用 `/memories/文件名.jpg` 一类路径。`identity` 使用 `purple` 或 `green`：紫色代表用户，绿色代表她。预置内容随构建提供，页面编辑和浏览器备份只管理本机添加的记录。

`personal-content.js` 的 `providedPhotoImport` 记录这批原图清单和校验值，首次导入的照片可在页面管理、备份；批次记录避免重复导入和删除后重新出现。额外静态 `memories/letters` 数组继续保留，目前为空。`npm run check:content` 检查本地文件、字段和原图哈希，不读取浏览器收藏。

## 场景与结构

主岛保留左侧记忆树、枝头白丝带、中部浅溪与天然踏石、前右薄瀑，以及右侧奶油白信箱和浅橡木长椅。白色雏菊、淡紫野花、少量柔和彩球、厚实不规则岩土断面、低处云层和远处小岛共同形成高空春日空间。

当前入口为 `src/natural/engine.js`。地形、材质、植物、水、道具与天空位于同目录的独立模块；`src/stories.js` 合并预置与本机内容并生成阅读层，`src/content-editor.js` 管理添加面板，`src/local-content.js` 负责事务保存与备份。旧原型文件保留，但不由当前入口引用。河石和植物使用实例化，家具合并网格，远岛降低细分；没有进行目标设备的正式帧率基准测试。

## 初见序章

轻触酒红火漆后输入暗号并启封，约 9 秒镜头从云端经过溪畔，停在真实白丝带挂点前；三片花瓣轻引导后自动释放。跳过按钮、Escape 或普通按键可结束运镜；减少动态效果偏好会直接到位，不播放花瓣。重播会重置信笺与声音。

可在项目根目录的 `.env.local` 配置 `VITE_OPENING_PASSPHRASE=0520`。未配置时允许空暗号；保底词默认是“春天”，可用 `VITE_OPENING_FALLBACK` 修改（设为空字符串可关闭）。直接看花园同样校验暗号。配置修改后需重启开发服务或重新构建。这是前端仪式入口，不能作为服务器身份认证或照片访问保护。

启封操作解锁现有声音系统：自然声 1 秒渐入（默认 60%，尊重已有音量及静音设置）；已收藏的本机音乐在第 1–4 秒渐入。未收藏音乐时仅播放自然声，不用替代歌曲。直接进入保持安静。离开页面暂停，回来后不会自行重播。

运行 `npm run test:ceremony` 验证暗号、真实音频渐入、完整运镜、三种跳过方式、重播、花瓣清理、减少动态效果及窄屏布局。测试使用独立的自动分配端口和浏览器存储，不修改日常浏览器收藏；记录保存在 `work/qa/ceremony/`。

## 绿意落叶与地表蒲公英风场

`src/natural/falling-foliage.js` 提供微凹花瓣、舟形叶片几何体和常驻双源粒子池：32 片树冠绿叶（0.26×0.52），28 粒草地蒲公英与白花瓣（0.22×0.22）。60 粒共享一个双面受光的 `InstancedMesh`，显式上传实例颜色，单次绘制；所有位置均属于世界坐标，移动镜头不会带走粒子。

384×128 内存 Canvas 图集分别绘制嫩绿水滴叶片、放射状白色绒毛和浅鹅黄边缘白花瓣。绿叶具有半透明主侧叶脉及翡翠绿至明黄绿渐变，使用绿色自发光 `#38a169`（0.18）；蒲公英使用蓬松羽毛伞与柔和径向辉光、白色自发光（0.28），白花瓣保留自然受光。三轴翻滚具有各自独立的周期与初相位，左右摇摆 30–60 度，曲面正反两侧自然交替受光，朝向完全不依赖镜头。

绿叶分散于整个树冠（x: -4.5–0.5、y: 3.8–7.8、z: -1.2–3.2），速度、升力与阻力具有 30–40% 的随机差异，并沿蜿蜒风道飘动；地表粒子从 `ground(x, z) + 0.05` 起步，静止时完全透明，随 7.5 秒阵风脉冲错时起飞并渐显，再缓慢浮沉。升力按帧时间积分，风带掠过溪流和长椅，循环池复用实例、属性与材质，销毁时释放几何体、材质和图集。

卡片、信箱等全屏阅读时停止风场时钟和 GPU 属性更新，关闭后从原位置继续；减少动态效果时隐藏并冻结，恢复设置后平稳恢复。初见导引仍使用三片微凹受光花瓣，采用米白色，并在结束后释放资源。

`npm run test:foliage`（或 `node scripts/review-falling-foliage.mjs`）验证真实地表发源、双源数量、世界坐标独立性、阵风升腾、地表隐匿、自由翻滚及速度离散、长期循环及资源释放，并通过浏览器检查 Canvas 图集、单次绘制、阅读休眠和减少动态效果。该脚本已纳入 `npm test`；验收记录、纹理图集、全景与树前截图位于 `work/qa/falling-foliage/`。

## 草坪生态与蝴蝶

`makeMeadowEcology` 在实际地形上布置 35 株蒲公英（21 株白茸种球、14 株金黄花）、150 朵溪岸勿忘我、12 颗湿润青苔卵石和 48 簇低矮三叶草。蓝花沿实际水线外 0.25–0.6 米错落分布；植株采用实例合批，和两只蝴蝶合计 7,978 个三角面。

蝴蝶停在随风摆动的真实花尖，以 1.2 Hz 轻扇翅膀。7.5 秒阵风超过 0.4 时或鼠标掠过附近花丛时起飞，盘旋 3.4 / 3.75 秒后落在另一朵花上。全屏阅读冻结植株与蝴蝶；减少动态效果时保持静止停歇。

`npm run test:meadow` 验证数量、两岸分布、地形接触、面数、扇翅周期、起降连续性、阅读休眠、无障碍切换和资源释放，已加入 `npm test`。截图与验收记录在 `work/qa/meadow-enrichment/`，整体场景截图仍由 `node scripts/review-overall-design.mjs` 更新。

## 清澈山泉与激流尾迹

`water.js` 使用 0.78 / 1.35 双层差速流纹与 0.022 法线振幅，按实际水深在浅青碧与翡翠蓝绿间过渡，保留河床卵石的透视。阳光高光随波峰及观察角度变化；五块跳石的真实错落坐标同时驱动水石模型和下游 V 型翻滚尾迹。瀑布口最后 0.4 米形成卷浪白沫，浅水轮廓贴合地形，并在出口连续收束至瀑布宽度。

所有动态共用场景时钟，阅读暂停后冻结，减少动态效果时保持静态。`npm run test:water` 用真实 WebGL 像素比较验证涟漪、高光、下游尾迹、跌水白沫及透明度，已纳入 `npm test`。`node scripts/review-overall-design.mjs` 同时更新 `screenshots/design-hero.png` 与新增的 `screenshots/design-creek.png`；水体专项指标和截图在 `work/qa/creek-fluidity/`。

## 重力飞瀑与翻滚水汽

`makeWaterfall` 使用 6.1 的下泻相位速度，以 `1 + 0.65 × depth^1.4` 表示随落差增加的局部速度，并积分逆速度建立稳定流动坐标，避免长时间访问后出现纹理反向。顶部按向外初速度和重力构成抛射水舌；中下段通过纵向噪声、透明撕裂和不规则法线形成翡翠水芯外的白色水束。

水汽使用 40 个合批点精灵与 128×128 多团柔化 Canvas 贴图，材质透明度 0.44。每团按独立生命周期膨胀、旋转、升腾和渐隐，覆盖瀑布下部与既有彩虹附近。水幕、水汽和溪流共用场景时钟，阅读暂停与减少动态效果都可冻结。

`npm run test:waterfall` 验证抛射弧线、加速方向、几何与水汽数量、资源释放、实际 WebGL 分股空隙、动画变化和休眠，已纳入 `npm test`。整体验收新增 `screenshots/design-waterfall.png` 特写；专项截图与 GPU 指标在 `work/qa/waterfall-liveliness/`。
